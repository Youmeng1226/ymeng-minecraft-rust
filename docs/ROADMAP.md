# 开发路线图

每个里程碑结束时都应该能跑起来、能演示。

## v0.1 — 引擎基础（进行中）

- [x] Cargo workspace，拆分 core / worldgen / mesh / client
- [x] 方块、区块、坐标类型及单元测试
- [x] Perlin / fBm 噪声，基于高度图的地形
- [x] 沙滩、海平面、树木
- [x] 隐藏面剔除网格构建
- [x] 区块 RLE 编码
- [x] GitHub Actions CI（fmt、clippy、test）

## v0.2 — 第一次看到画面

- [ ] `winit` 窗口 + `wgpu` 渲染管线
- [ ] 纹理图集加载（自制 16×16 像素材质）
- [ ] 自由飞行相机（WASD + 鼠标）
- [ ] 视锥剔除
- [ ] 简单的方向光 + 环境光遮蔽（AO）
- [ ] 帧率 / 坐标调试面板

## v0.3 — 无限世界

- [ ] 以玩家为中心动态加载 / 卸载区块
- [ ] 后台线程池生成区块和网格（`rayon` 或自建任务队列）
- [ ] 贪婪网格（Greedy Meshing）减少面数
- [ ] 3D 噪声：洞穴、悬崖
- [ ] 生物群系：平原、森林、沙漠、雪地
- [ ] 跨区块的树木 / 装饰物生成

## v0.4 — 可以玩了

- [ ] 玩家物理：重力、碰撞（AABB）、跳跃
- [ ] 射线检测选中方块（DDA）
- [ ] 破坏 / 放置方块，网格局部重建
- [ ] 快捷栏与基础物品
- [ ] 存档 / 读档（基于现有 RLE 格式 + 区域文件）

## v0.5 — 世界更有生气

- [ ] 光照传播（天空光 + 方块光）
- [ ] 昼夜循环与天空盒
- [ ] 流动的水
- [ ] 音效

## 远期

- [ ] 多人联机（独立服务器 crate，基于 UDP / QUIC）
- [ ] 数据驱动的方块与物品定义（RON / TOML）
- [ ] 简单的生物 AI
- [ ] 模组接口（WASM 插件）

## 性能目标

| 指标 | 目标 |
| --- | --- |
| 视距 | 16 区块 |
| 帧率（中端显卡） | ≥ 144 FPS |
| 单区块生成 + 网格 | < 1 ms |
| 内存（16 区块视距） | < 1 GB |
