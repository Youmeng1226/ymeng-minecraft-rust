# 架构设计

## Crate 划分

```
ymc-client ──► ymc-mesh ──► ymc-core
     │                        ▲
     └──────► ymc-worldgen ───┘
```

| Crate | 职责 | 依赖 |
| --- | --- | --- |
| `ymc-core` | `Block`、`Chunk`、坐标类型，不依赖任何外部库 | 无 |
| `ymc-worldgen` | 噪声函数和 `TerrainGenerator` | core |
| `ymc-mesh` | 把 `Chunk` 转成顶点 / 索引缓冲 | core |
| `ymc-client` | 世界管理、渲染、输入、游戏循环 | 全部 |

计划新增：`ymc-render`（wgpu 封装）、`ymc-physics`、`ymc-server`、`ymc-protocol`。

## 坐标系

- Y 轴向上，区块大小 16 × 128 × 16。
- `BlockPos`：世界中的绝对方块坐标（`i32`）。
- `ChunkPos`：区块列坐标，`BlockPos` 用 `div_euclid` 转换，负坐标也正确。
- `LocalPos`：区块内坐标（`usize`），用 `rem_euclid` 计算。

## 区块存储

方块按 `(y * 16 + z) * 16 + x` 平铺存储在 `Box<[Block; 32768]>` 中，每个方块 1 字节。同一水平层的数据在内存中连续，按层遍历（地形生成、网格构建）时缓存友好。

`dirty` 标记用于判断是否需要重建网格。

存盘时使用 RLE 编码 `(block_id, run_length)`。地形大部分是成片的石头和空气，压缩效果很好。

## 地形生成

1. 用 5 个八度的 fBm Perlin 噪声得到基础高度，再叠加一层高频细节噪声。
2. 每一列从下往上填充：基岩 → 石头 → 泥土 → 草 / 沙，高度低于海平面的部分填水。
3. 用区块坐标派生的确定性随机数放置树木，同一种子总是生成同样的世界。

后续会引入 3D 噪声（洞穴）和生物群系噪声（温度 / 湿度）。

## 网格构建

- 对每个可见方块的 6 个面，检查相邻方块；相邻方块不透明时剔除该面。
- 相同类型的透明方块之间（如水与水）不生成面。
- 不透明方块和透明方块分到两个缓冲，渲染时先画不透明，再按距离排序画透明。
- 区块边界处通过 `NeighborLookup` 查询相邻区块。

下一步：贪婪网格合并共面的相同方块，预计减少 60%–80% 的面。

## 渲染（规划中）

- `wgpu` + WGSL 着色器，顶点格式就是 `ymc_mesh::Vertex`。
- 一张纹理图集，`Vertex::texture` 为图集索引。
- 每个区块一个 GPU 缓冲，区块网格重建时只上传变化的区块。

## 线程模型（规划中）

```
主线程: 输入 → 更新 → 提交渲染
工作线程池: 区块生成 → 网格构建 → 通过 channel 发回主线程
```
